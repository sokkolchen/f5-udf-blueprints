# F5 UDF demo blueprints

Descriptions and images for F5 UDF demo blueprints. One folder per blueprint.
The `UDF-DOCUMENTATION.md` in each folder is the text pasted into the blueprint description in UDF;
its images are loaded from this repository.

| Folder | Blueprint |
|---|---|
| [guardrails-agent](guardrails-agent/UDF-DOCUMENTATION.md) | F5 AI Guardrails – Arcadia Bank AI Agent Demo |

## Adding a blueprint

1. Create a folder with a short name, e.g. `my-demo/`.
2. Put `UDF-DOCUMENTATION.md` and an `img/` folder in it.
3. Link images as `https://raw.githubusercontent.com/sokkolchen/f5-udf-blueprints/main/<folder>/img/<file>.png`.
4. Add a row to the table above.
